## Locked design decisions (planner, binding for the executor)

1. **Deploy order (same as 025):** migration 026 must be applied in Supabase Studio BEFORE this code is merged to main (Vercel deploys main). Single-campaign reads stay tolerant of a missing column: they keep `select("*")` and map `endsAt: row.ends_at ?? null`, so letter generation, public pages and the manage page work before 026. List queries (`getRecentActiveCampaigns`, `getLandingCampaigns`) filter on `ends_at` in SQL and therefore require 026; before 026 they error (landing pills, not-found list and ended-view list catch to `[]`, `/ngo-briefkampagne` would 500). `createCampaign` only sends `ends_at` when an end date was chosen, so creation without an end date keeps working even if 026 lags. Write this requirement into the migration header comment.
2. **Read semantics:** `getActiveCampaignBySlug` / `getActiveCampaignByCompactSlug` keep their current query (status active + moderation approved) and therefore still return ended campaigns. "Ended" is orthogonal to `status`. Public page, root alias and OG image keep resolving ended campaigns without changes to those queries. Letter-pipeline callers apply `runningCampaign(found, new Date())` to drop ended campaigns.
3. **End instant:** `ends_at` = 23:59:59.000 Europe/Berlin wall time on the chosen calendar day. `isCampaignEnded(c, now)` = `c.endsAt != null && now.getTime() >= Date.parse(c.endsAt)`. "Kampagne jetzt beenden" stores the current instant.
4. **Type compatibility:** `Campaign.endsAt` is optional (`endsAt?: string | null`, like `topic?`) so the ~15 existing test fixtures typed `Campaign` keep compiling under ts-jest. Missing/undefined counts as running.
5. **Prop-driven ended state (for the orchestrator's browser check):** the public page computes `isCampaignEnded(campaign, new Date())` in one line in `kampagne/[slug]/page.tsx`; the manage page computes `ended` in `kampagne/verwalten/page.tsx` and passes it to `CampaignManager`. `CampaignEndedView` takes plain props. A temporary local override of `endsAt` at those two spots is enough to preview both ended states.
6. **Ending a paused campaign:** `endCampaignNow` on a `paused` campaign also sets `status: "active"` so the public ended view is reachable (a paused campaign 404s). Ending is allowed from draft, awaiting_email_verification, awaiting_approval, active, paused.
7. **No migration application:** never run `supabase db push`, Studio SQL, or any MCP/remote SQL. There is no local Supabase/docker. Report migration state as: file created, not applied locally, not applied remotely.

German, informal "du" as in the existing campaign UI, no em dashes and no en dashes used as Gedankenstriche (use commas, colons, full stops), concrete and short. Check every new string against `/Users/thomas/Documents/Git Repos/signs-of-ai-writing.md` (no puffery words, no rule-of-three adjective piles, no "nicht nur X, sondern auch Y"). Locked strings from the story: "Diese Kampagne ist seit {Datum} beendet", "{n} Briefe wurden über diese Kampagne formuliert" (singular: "1 Brief wurde über diese Kampagne formuliert", omit the line when n is 0), "Schreib deinen eigenen Brief nach Berlin", "Kampagne jetzt beenden", "Kampagne pausieren", "Beendet am {Datum}", "Kontakt aufnehmen", quick choices "Kein Enddatum", "2 Wochen", "1 Monat", "3 Monate", "Eigenes Datum". Date display: `formatCampaignEndDate` (de-DE long month, Europe/Berlin), for example "22. Oktober 2026".
