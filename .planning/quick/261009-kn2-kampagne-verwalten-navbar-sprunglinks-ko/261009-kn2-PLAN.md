# Kampagne verwalten: Navbar mit Sprunglinks + Kontakt, Zahlen-Refresh

## Context
On /kampagne/verwalten the main navbar shows only "Brief-nach-Berlin". The jump links sit in a separate sticky second row (SectionNav `variant="header"`, commit `946c10a`, local only, not deployed). Thomas wants:
1. The jump links in the main navbar: **Teilen · Zahlen · Feedback · Bearbeiten**. "Spenden" goes away.
2. A secondary CTA at top right to contact him by email, using `BRIEF_EMAIL` from `lib/contact.ts`.
3. A small refresh icon next to the letter count, usable once per 60 s.
4. New copy: "1.939 Briefe nach Berlin geschrieben".

Decided layout: on desktop (md+) everything is one row (logo, links in the middle, Kontakt on the right). On mobile the main row holds logo and Kontakt, with a narrow jump-link row below it.

Run it through `/gsd:quick`. Frontend changes follow `/frontend-design` (memory: UI skills for frontend).

## Approach

### 1. Slots in AppHeader (`web/src/components/AppHeader.tsx`)
- Add two empty, layout-neutral slots to `<nav>`:
  - `data-app-header-center`: `hidden md:flex flex-1 justify-center min-w-0`, between the logo and the right group.
  - `data-app-header-actions`: inside the existing right `div` (always visible).
- Leave everything else unchanged. The NGO links and the language switcher stay as they are.

### 2. SectionNav header variant uses portals (`web/src/components/internalStats/SectionNav.tsx`)
- New optional prop `actions?: ReactNode` (the Kontakt button).
- After mount (`useEffect` + state), look up the slot elements and render with `createPortal`:
  - links → `[data-app-header-center]`, in the desktop style (text-sm, active state shown as underline/color like now)
  - `actions` → `[data-app-header-actions]`
- Mobile: the existing sticky second row stays, plus `md:hidden`.
- Shared: the existing IntersectionObserver `active` state. The `scrollIntoView` for the active link only applies to the mobile list (via a ref, not a global `querySelector`, because the link now exists twice).
- Leave the `"page"` variant (/stats) unchanged.
- Without JS: the mobile row stays as plain anchor links. The desktop links only appear after hydration (acceptable trade-off).

### 3. Links + Kontakt on the page (`web/src/app/(site)/kampagne/verwalten/page.tsx`)
- `sectionLinks`: `campaign-share` "Teilen", if stats exist then `creator-stats` "Zahlen" + `creator-feedback` "Feedback", always `campaign-settings` "Bearbeiten". Remove Spenden.
- Kontakt CTA as `actions`: secondary style (outline/text, not filled green), envelope icon + "Kontakt", `min-h-11`. On mobile it may become icon + short text.
- Add helper `campaignContactHref(slug)` to `web/src/lib/contact.ts`. It reuses the existing mailto (`Kampagne <slug>` as subject) from `CampaignManager.tsx:166`, and both places use it.

### 4. Feedback anchor (`web/src/components/campaigns/CampaignCreatorStats.tsx`)
- Put `id="creator-feedback"` + `scroll-mt-32` on the wrapper of the feedback block. That block is always one of `unavailable`/`collecting`/`ready` as soon as stats exist; if needed, a single wrapper around the three branches.
- Copy: `"Brief nach Berlin geschrieben"` / `"Briefe nach Berlin geschrieben"`.

### 5. Refresh button (new `web/src/components/campaigns/CreatorStatsRefresh.tsx`, client)
- `CampaignCreatorStats` is a server component, so the refresh is a small client island next to the count.
- `useRouter().refresh()` inside `useTransition`. That re-renders the page on the server; `getCampaignCreatorStats` has no cache. The pattern is already used in `CampaignManager.tsx` (`router.refresh()` after actions).
- 60 s cooldown in client state (timestamp of the last refresh, initially the mount time). Afterwards a small label: "gerade aktualisiert" / "vor X Min. aktualisiert", updated every 30 s.
- Icon button ↻ with `aria-label="Zahlen aktualisieren"`. While pending it spins (`motion-reduce` off). During the cooldown it is `disabled` with title "Gleich wieder möglich". Touch target 44px.
- No server rate limit, because reloading the page does exactly the same thing.
