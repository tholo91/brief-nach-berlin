# Kampagnenseiten: Zähler, Disclaimer, pausiert per Link, "Weitere Kampagnen"

## Context
Thomas wants four changes to the campaign pages:
1. The letter counter should only appear above 20 letters.
2. The disclaimer should state clearly that the campaign is responsible for its own content.
3. Paused campaigns should stay reachable by direct link and still work for creating letters (so he can test with logos), but must not appear in any list.
4. A secondary "Weitere Kampagnen" button should appear at the right of the navbar.

Today, paused campaigns return a 404 and letters for them are rejected. Thomas decided they should be reachable by direct link, so the NGO-facing copy that says pausing "hides the page" has to change too.

Execute this via `/gsd-quick`. The UI parts (button, hero) go through `/frontend-design`.

**Dirty worktree:** `api/generate-letter/route.ts` and `generateLetterRouteHardening.test.ts` already have local changes. Edit them carefully and keep those changes intact.

## 1. Counter only above 20
- Add a shared constant `PUBLIC_LETTER_COUNT_MIN = 20` in `web/src/lib/campaigns/` (next to schema or endDate, e.g. a new `display.ts`).
- Use it in three places:
  - `CampaignList.tsx:71`, which today hardcodes `> 20`.
  - `CampaignHero.tsx:250`: render the line only when `letterCount > MIN`.
  - `CampaignEndedView.tsx` `letterCountSentence`: return `null` when `count <= MIN`, so the ended view behaves the same way.
