## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> resendLetterAction (public server action) | caller controls WizardData (e-mail, PLZ, issue), selection, letter text and proof |
| browser -> createCampaignDraftAction (public server action) | caller controls all form fields, logo file and the creator e-mail that receives a mail |
| browser -> /api/generate-letter | caller controls the body; the response tells the client whether a retry is safe |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-oy6-01 | Spoofing / Tampering | resendLetterAction | high | mitigate | Task 2: verified generation proof required for every recipient kind and bound via doesGenerationProofMatch to issue, PLZ, recipient, letter text and campaign; rejected before rate limits and mail, so the action cannot send arbitrary text to arbitrary addresses |
| T-oy6-02 | Denial of Service (cost) | createCampaignDraftAction | medium | mitigate | Task 3: IP and e-mail buckets (LIMITS.CAMPAIGN_DRAFTS, 5 per hour) checked before logo storage upload, paid moderation, DB insert and Brevo mail |
| T-oy6-03 | Information Disclosure | rate-limit bucket keys | low | mitigate | Task 3: e-mail and IP pass through hashIdentifier (salted SHA-256) before use as keys; test asserts no key contains the plain e-mail |
| T-oy6-04 | Tampering (duplicate mail) | generate-letter generic 500 | low | mitigate | Task 1: retrySafe only on the generic 500, valid because after() is registered after every throwing step; test asserts after() was not called on the 500 path |
| T-oy6-05 | Denial of Service | in-memory limiter | low | accept | Buckets are per Vercel instance and reset on deploy (documented caveat in web/src/lib/rateLimit.ts); stops scripted abuse from one origin, which is the goal |
| T-oy6-06 | Denial of Service (usability) | resend after proof expiry | low | accept | Proof TTL is 24 h; a resend from a tab open longer fails with the generic error and the user can generate again (Bauprinzip: rare cases fail cleanly) |
