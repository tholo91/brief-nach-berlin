# S4 Unterrichtsmaterial `/schule/ablauf` (druckbar, ohne PDF-Lib)

Ziel: Eine Lehrkraft druckt am Abend vorher drei saubere A4-Seiten aus: Stundenablauf, Arbeitsblatt „Mach den Brief zu deinem“ (25 Kopien), Tafelbild Bund, Land, Kommune. Am Bildschirm ist die Seite normal lesbar, gedruckt ohne Header, Footer, Navigation und ohne Farbflächen.

## Designrichtung (frontend-design)

Druck zuerst: schwarz-weiß tauglich, Linien statt Flächen, Waldgrün nur für Überschriften (wird grau gedruckt, bleibt lesbar). Typewriter für Überschriften, Body-Sans für Text, Schreiblinien als dünne graue Linien. Jede der drei Seiten ist ein eigenes Blatt (`break-before: page`), nichts bricht mitten in einer Tabelle oder Checkliste (`break-inside: avoid`). Am Bildschirm: eine Spalte, Button „Seite drucken“ oben (`window.print()`, im Druck ausgeblendet), Link zurück zu `/schule`.

## Befund des PO vor dem Start (wichtig)

Die globale Regel `@media print { body > *:not(main) { display: none !important; } }` in `globals.css` macht jede Seite unter `app/(site)/` beim Drucken leer, weil das Site-Layout `body > div > (header, main, footer)` rendert (geprüft: `/impressum` druckt als leere Seite). Bestehende Druckseiten liegen deshalb außerhalb des Site-Layouts unter `web/src/app/print/osterholz/flyer|poster/page.tsx` mit `<main>` direkt im `body`. Für `/schule/ablauf` dasselbe Muster nutzen: `web/src/app/schule/ablauf/page.tsx` (außerhalb der Route-Gruppe `(site)`, Pfad bleibt `/schule/ablauf`), mit eigener schlanker Kopfzeile am Bildschirm (Marke als Link zur Startseite, „Zurück zur Seite für Schulen“, Button „Seite drucken“), die im Druck ausgeblendet ist. Prüfen, dass `/schule` (in `(site)`) und `/schule/ablauf` (außerhalb) im Build ohne Routen-Konflikt nebeneinander laufen. Die globale Regel nicht ändern.
