# Schulname im Klassenlink

Lehrkraft kann im Klassenlink-Generator optional "Schule und Ort" eingeben. Der Wert reist im signierten Klassen-Token, das Kind sieht ihn gesperrt im Formular, der Brief nennt Schule und Ort einmal in der Vorstellung. Nichts wird gespeichert (keine Tabelle, kein Log). Alte Tokens ohne Schulnamen funktionieren unverändert.

Locked decisions (do not revisit): optional field; inside signed token as `s`; prefilled and NOT editable for the child; mentioned once in the introduction for every topic; transient only (Mistral prompt, not persisted/logged); QR gets bigger instead of storing data; no new libraries; no Supabase changes.

All paths are repo-root-relative. Commands run from `web/`. Mistral is always mocked in tests (`@/lib/mistral`). Only `*.test.ts` files run in Jest (no `.test.tsx`).

## Task 1: Token, QR capacity, link action

files:
- web/src/lib/schule/classToken.ts
- web/src/lib/schule/youth.ts (shared constant `SCHULE_MAX_CHARS` + `normalizeSchule()` helper usable client + server)
- web/src/lib/qr-code.ts
- web/src/lib/actions/createClassLink.ts
- tests: web/src/__tests__/ (extend existing class token / QR tests if present, else new `classTokenSchule.test.ts`, `qrCodeVersions.test.ts`)

action:
- `normalizeSchule(value: unknown): string | undefined`: string only, NFC, strip control chars, collapse whitespace, trim, empty → undefined, longer than `SCHULE_MAX_CHARS` → undefined (reject, do not cut). Choose `SCHULE_MAX_CHARS` (around 60) so the worst case fits the QR (see below).
- Token payload: optional `s: z.string()` re-validated with `normalizeSchule` on verify (invalid → whole token invalid? No: drop `s`, keep token valid). `signClassToken({..., schule})` sets `s` only when present. `verifyClassToken` returns `schule?: string`.
- QR: `createQrMatrix` currently hardcodes version 10-Q (151 byte payload). Refactor constants into a per-version table and pick the smallest supported version that fits: keep 10-Q, add one larger Q version (e.g. 15-Q or whichever fits the worst case). Take block structure, alignment pattern positions and version-info bits from the ISO 18004 tables; check every hardcoded v10 assumption (alignment positions, size, version bits, remainder bits). URLs that fit v10 must produce a byte-identical matrix to today (regression test: snapshot or compare to current output for a sample URL).
- Worst case to fit: `${APP_URL}/schule?k=` + token with level set, pdf delivery, Klasse 13, and a school name of `SCHULE_MAX_CHARS` characters that are all multi-byte umlauts (e.g. "ü"). Token MAC: with `s` present use the short MAC like the fixed level does if needed. Add a test that signs this worst case and encodes it without throwing.
- `createClassLinkAction`: accept optional `schule`; normalize; if provided but invalid → `invalid_input` with a message mentioning the max length.

verify: `cd web && npx jest classToken qr` green; regression test proves v10 output unchanged.
done: token round-trips with/without `s`; old tokens verify; worst-case QR encodes.
